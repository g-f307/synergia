# Registro de teste cruzado de recuperação

Estado: pendente de execução independente.

Este formulário não constitui evidência até ser preenchido por uma pessoa
diferente do autor da implementação. Não anexar bundle, manifesto privado,
credenciais, conteúdo, nomes de arquivo, e-mails ou hashes completos.

| Campo | Registro |
| --- | --- |
| executor | pendente |
| ambiente isolado e versão PostgreSQL | pendente |
| data/hora inicial e final | pendente |
| bundle dentro da retenção | pendente |
| backup | pendente |
| restauração em banco vazio | pendente |
| migrations e integridade | pendente |
| arquivos presentes/ausentes/corrompidos | pendente |
| expurgo permitido/proibido | pendente |
| indisponibilidade e retomada | pendente |
| RPO/RTO observados | pendente |
| decisão e observações sanitizadas | pendente |
